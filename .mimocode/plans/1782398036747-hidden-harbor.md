# Plan: Mostrar toda la informacion de la solicitud en el modal de aprobacion

## Contexto
El formulario de solicitud publico (cliente) recopila 6 tipos de datos: datos personales, info laboral, ubicacion, referencias, datos bancarios y verificacion. Pero el modal de aprobacion del admin solo muestra datos personales y prestamo. La info laboral, direccion, referencias y banco se guardan en la BD pero nunca se retornan ni se muestran.

## Archivos a modificar

### Backend (5 archivos)

**1. `backend/src/PréstamoPlus.Application/DTOs/SolicitudDtos.cs`**
- Agregar propiedades a `LoanApplicationDto`: `WorkInformation`, `Address`, `References`, `BankAccount`

**2. `backend/src/PréstamoPlus.Application/Features/Solicituds/Specifications/LoanApplicationSpecifications.cs`**
- `LoanApplicationByIdWithClientSpec`: agregar `.Include(l => l.Client).ThenInclude(c => c.WorkInformation)`, `.ThenInclude(c => c.Address)`, `.ThenInclude(c => c.References)`, `.ThenInclude(c => c.BankAccount)`
- `AllLoanApplicationsWithClientSpec`: mismos includes

**3. `backend/src/PréstamoPlus.Application/Features/Solicituds/Queries/GetAllSolicituds/GetAllSolicitudsQueryHandler.cs`**
- Mapear las nuevas propiedades (WorkInformation, Address, References, BankAccount) en el `.Select()`

**4. `backend/src/PréstamoPlus.Application/Features/Solicituds/Queries/GetSolicitudById/GetSolicitudByIdQueryHandler.cs`**
- Mapear las mismas propiedades

**5. No necesita migracion** - Las tablas Addresses, WorkInformations, References, BankAccounts ya existen en la BD con FK a Clients. Solo se cambia lo que se retorna.

### Frontend (1 archivo)

**6. `src/components/modals/SolicitudDetailModal.jsx`**
- Agregar seccion "Ubicacion" con: direccion, ciudad, provincia, sector, codigo postal
- Agregar seccion "Datos Bancarios" con: banco, tipo cuenta, numero cuenta
- Agregar seccion "Referencias Personales" con las 2 referencias (nombre, relacion, telefono)
- Seccion "Informacion Laboral" ya existe como dead code - ahora se activara con los datos reales del backend
- Agregar info de prestamo: frecuencia de pago, unidad de plazo

## Flujo de datos

```
Cliente llena formulario -> CreateSolicitudCommand -> Guarda Client + WorkInformation + Address + References + BankAccount + LoanApplication
                                                                          |
Admin ve modal          <- GetAllSolicitudsQuery <- Spec con Includes    <-/
```
